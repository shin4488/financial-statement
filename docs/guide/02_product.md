# 02. プロダクト仕様

財務3表の見方、CFパターン、ROE・ROAの計算条件、対応する会計基準、基本操作は [Webガイド](https://investee.info/guide) を参照。この章は、Webガイドにない検索・更新・表示の仕様を補足する。

## データの扱い

| 項目 | 仕様 |
|---|---|
| カードの単位 | 企業の会計期間ごと。同じ企業の過年度のカードも並ぶ |
| 連結 / 単体 | 連結の科目が欠けても、単体の値を混ぜない |
| 訂正書類 | 同じ企業・会計期間のデータを更新する。財務数値のない訂正書類で、既存の科目を空にしない |
| 並び順の日付 | 保存した提出日を使う。訂正書類は元の有報の日付になる場合がある |
| ファンド | 提出した企業自身の財務ではないため比較対象にしない |

## 検索と画面の状態

| 項目 | 仕様 |
|---|---|
| 検索URL | URLから同じ検索条件を開ける。更新前の数値を固定して共有する機能ではない |
| CFパターンの境界 | 0と欠損は、正負のどちらにも含めない |
| 自動切替 | ON / OFFの設定をブラウザに保存する |
| 通信エラーと0件 | 別の案内を表示し、取得失敗を「該当なし」と扱わない |
| 一部の表が表示不可 | BS・PL・CFを個別に判定し、表示できる表は表示する。欠けた金額を0円とは扱わない |

## ROE・ROAの表示と企業公表値の扱い

| 条件 | 扱い |
|---|---|
| 一部の指標が計算できない・赤字・利益0 | 各指標を個別に計算し、計算できるものは表示する。赤字や利益0だけを理由に非表示にしない |
| ROEを計算できる | 当サイトの計算値を優先する |
| ROEの計算に必要なデータが不足 | 同じ書類・会計基準・連結区分の企業公表ROEがあれば使う。ただし、平均自己資本が0以下と分かる場合は補完しない |
| 企業公表ROEを表示する | 原本の計算条件に従う値のため、当サイトの計算式や内訳の積と一致しない場合がある |

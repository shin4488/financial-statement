# 02. プロダクト仕様

investee（https://investee.info ）は、企業の財務カードを並べて比較するサービス。ここでは、画面とデータの扱いについて知っておくべき仕様をまとめる。取込・配信の仕組みは[03 章](03_data_flow.md)、構成と運用上の制約は[04 章](04_system.md)を参照。

## 比較するデータ

| 項目           | 仕様                                                                                                             |
| -------------- | ---------------------------------------------------------------------------------------------------------------- |
| 出典・更新     | EDINET の有価証券報告書・訂正有価証券報告書を定期的に取り込む。リアルタイムの業績や予想値ではない                |
| カードの単位   | 企業の会計期間ごと。同じ企業の過年度のカードも並ぶ                                                               |
| 連結 / 単体    | 連結を作成する企業は連結、作成しない企業は単体を表示する。連結の科目が欠けても単体の値を混ぜない                 |
| 訂正書類       | 同じ企業・会計期間のデータを更新する。財務数値のない訂正書類で、既存の科目を空にしない                           |
| 企業名・並び順 | 各書類に記載された企業名を使い、保存した提出日の新しい順に並べる。訂正書類の日付は元の有報の日付になる場合がある |
| ファンド       | 提出した企業自身の財務ではないため比較対象にしない。過去に誤登録したファンドも、データを保持して一覧から除外する |

証券コードが空欄の過年度書類は、取得した原本の書類 ID・EDINET 企業コード・会計期間が保存済みの書類とすべて一致する場合に限り再取込する。企業名だけで別の書類を結び付けない。

## 画面と操作

ログインせずに利用できる。カードには企業名、証券コード、会計期間、連結 / 単体を表示し、日本基準以外は会計基準も併記する。

| 操作                  | 挙動                                                                                       |
| --------------------- | ------------------------------------------------------------------------------------------ |
| 証券コードで検索      | 複数の企業を絞り込める                                                                     |
| CF パターンで絞り込み | 営業・投資・財務 CF の正負の組合せで絞り込める                                             |
| カードの切替          | BS → PL → CF → ROE・ROA を、自動または手動で切り替える。自動切替の設定はブラウザに保存する |
| スクロール            | 続きのカードを追加で読み込む。列数は画面幅に合わせて変わる                                 |
| 企業名を選択          | 株探の銘柄ページを別タブで開く                                                             |
| URL を共有            | 同じ検索条件を開ける。データ更新後も同じ数値を固定表示する機能ではない                     |

## 財務 3 表の表示

| 表  | 見せ方                                                     | 数値の意味                             |
| --- | ---------------------------------------------------------- | -------------------------------------- |
| BS  | 資産と、負債・純資産を並べる。債務超過は別の棒で示す       | 総資産に対する割合                     |
| PL  | 売上と費用・利益を並べる。営業損失は売上側に表示する       | 売上高に対する割合                     |
| CF  | 期首残高から営業・投資・財務の増減を経て、期末残高へつなぐ | 残高と増減額。増加と減少を色で区別する |

BS・PL はグラフ上の項目に触れると金額を確認できる。銀行・保険などは、開示形式に合わせた科目や利益を使う。

CF の期末残高は原本の金額を表示する。為替の影響などにより、期首残高と 3 区分の増減の合計に一致しない場合がある。

### 表示できない場合

日本基準・IFRS でも、開示形式や必要な科目の有無によって表示できない表がある。米国基準などの未対応形式も、エラー画面ではなく説明文を表示する。BS・PL・CF はそれぞれ判定し、1 つを表示できなくても他の表は表示する。

通信エラーと検索結果 0 件は別の案内を表示する。欠けた金額を 0 円とは扱わない。原本の取得に失敗した場合も既存データを消さず、取得できていない値は未取得のまま扱う。

日本基準 CF で日付から期首現金を特定できない場合は、同じ原本の期首候補・当期増減・調整額・期末額を照合する。企業・連結区分が一致する円建ての値で、開示時の丸めを考慮して金額が整合する候補を 1 つに絞れた場合だけ、**原本の期首額を使う**。総資産・自己資本の期首残高にはこの補完を使わない。

## CF パターンによる絞り込み

3 区分の増減を次の 8 パターンに分類する。名前は資金の動きを読むための目安で、企業の安全性や投資価値を判定するものではない。0 や欠損は正負のどちらにも含めない。

| パターン     | 営業 | 投資 | 財務 |
| ------------ | ---- | ---- | ---- |
| 健全型       | ＋   | −    | −    |
| 積極型       | ＋   | −    | ＋   |
| 安定型       | ＋   | ＋   | ＋   |
| 改善型       | ＋   | ＋   | −    |
| 勝負型       | −    | −    | ＋   |
| リストラ型   | −    | ＋   | −    |
| 大幅見直し型 | −    | −    | −    |
| 救済型       | −    | ＋   | ＋   |

## ROE・ROA

### 計算と表示

| 指標                     | 計算式                           |
| ------------------------ | -------------------------------- |
| ROE                      | 純利益 ÷ 平均自己資本 × 100（%） |
| ROA                      | 純利益 ÷ 平均総資産 × 100（%）   |
| 売上高純利益率（収益性） | 純利益 ÷ 売上高 × 100（%）       |
| 総資産回転率（効率性）   | 売上高 ÷ 平均総資産（回）        |
| 財務レバレッジ（健全性） | 平均総資産 ÷ 平均自己資本（倍）  |

- 平均は同じ書類の期首・期末の平均。期末だけでは代用しない。1 年未満の決算でも年率換算しない。
- 連結では親会社株主に帰属する純利益、単体では当期純利益を使う。自己資本には非支配株主持分や新株予約権などを含めない。
- 各指標は独立して計算する。売上高がなくても利益と残高があれば ROE・ROA は算出できる。銀行・保険の経常収益を売上高の代わりにはしない。

カードは「ROE = 売上高純利益率 × 総資産回転率 × 財務レバレッジ」「ROA = 売上高純利益率 × 総資産回転率」の形で並べる。回転率とレバレッジは%表示に回数・倍率を添える。計算途中では丸めず、表示時に丸めるため、画面の数値を掛けた結果には端数の差が出る。

色は項目の区別に使う。レバレッジが高いほど健全という意味ではない。

### 欠損と企業公表 ROE

| 状態                                                                        | 表示・扱い                                                                      |
| --------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| 必要な値がない                                                              | 「データなし」。取得できた他の指標は表示する                                    |
| 計算の分母が 0 以下                                                         | 「算出不可」。赤字や利益 0 は、この理由だけで非表示にはしない                   |
| ROE を計算するデータが不足し、同じ書類・会計基準・連結区分の公表 ROE がある | 「企業公表値」と明示して表示する。平均自己資本が 0 以下と分かる場合は補完しない |
| ROA 行のレバレッジ欄                                                        | 計算対象外なので「—」を表示する。欠損には使わない                               |

公表 ROE は当サイトで計算できるかどうかにかかわらず取得・保存する。表示は当サイトの計算値を優先する。企業の計算条件は原本の注記に従うため、当サイトの計算式や内訳の積と一致するとは限らない。公表 ROE から不足する残高を逆算しない。

## 説明・案内ページ

フッタから各ページへ移動できる。計算条件や読み方はガイドにまとめ、各カードに長い説明を繰り返さない。

| URL        | 内容                                                                                |
| ---------- | ----------------------------------------------------------------------------------- |
| `/about`   | サービス概要、出典、更新、免責事項、運営者情報                                      |
| `/guide`   | 財務 3 表の読み方とグラフ例、CF パターン、ROE・ROA の定義、会計基準・業種による違い |
| `/privacy` | 計測・広告、ブラウザに保存する設定、問い合わせ情報の扱い                            |
| `/contact` | 問い合わせフォームと報告時に必要な情報                                              |

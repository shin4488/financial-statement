# 02. プロダクト仕様

財務3表の見方、CFパターン、ROE・ROAの計算条件、対応する会計基準、基本操作は [Webガイド](https://investee.info/guide) を参照。この章は、Webガイドと他の章にない検索・表示の仕様を補足する。

| 項目 | 仕様 |
|---|---|
| カードの単位 | 企業の会計期間ごと。同じ企業の過年度のカードも並ぶ |
| FCFの5年推移 | 各年の主たる財務諸表を使い、連結・単体が切り替わる場合は注記する |
| 検索URL | URLから同じ検索条件を開ける。更新前の数値を固定して共有する機能ではない |
| CFパターンの境界 | 0と欠損は、正負のどちらにも含めない |
| 通信エラーと0件 | 別の案内を表示し、取得失敗を「該当なし」と扱わない |
| 赤字・利益0のROE・ROA | 赤字や利益0だけを理由に非表示にしない |
| 企業公表ROEの代用 | 平均自己資本が0以下と分かる場合は使わない。企業と当サイトで計算条件が異なる場合があるため、当サイトの計算式や内訳の積と一致するとは限らない |
